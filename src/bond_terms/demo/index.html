bond-terms

Lire les conditions d'une obligation, avec la preuve de chaque valeur

Quand une entreprise ou une banque emprunte sur les marchés, elle émet une obligation : une dette avec un montant, un taux d'intérêt et une date de remboursement. Ces conditions sont écrites dans un document officiel de 10 à 200 pages.

Dans une banque, on les recopie souvent à la main : environ 3 minutes par document, avec des erreurs. bond-terms les lit automatiquement, cite la phrase exacte du document pour chaque valeur, et signale quand la base officielle de l'autorité européenne des marchés (ESMA) dit autre chose.

Essayer

Choisissez un exemple, ou saisissez le code d'une obligation (son ISIN).

Comment lire une fiche

  • Vérifiée La valeur a été lue, et la phrase citée a été retrouvée telle quelle dans le document.
  • À contrôler La valeur a été lue, mais sa preuve n'a pas pu être vérifiée : elle n'est pas retenue.
  • Non trouvée Le document ne donne pas cette information, ou l'outil ne l'a pas trouvée.
  • Écart La base officielle de l'ESMA indique une autre valeur. Ce n'est pas forcément une erreur de l'outil : souvent, la base est mise à jour après le document (montant réellement placé, abondement).
  • Relecture humaine : quand une valeur importante n'a pas pu être prouvée, le document est signalé pour qu'une personne le vérifie.
